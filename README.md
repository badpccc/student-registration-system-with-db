## How to Run

1. Clone this repository.
2. Open the project in your preferred Java IDE.
3. Make sure Java and MySQL are installed.
4. Open `src/main/resources/application.properties`.
5. Update the database username and password with your own credentials:

```properties
spring.datasource.username=YOUR_DB_USER
spring.datasource.password=YOUR_DB_PASSWORD
```

6. Start the application by running `SistemaAlunosApplication.java`.

The application will start on:

```text
http://localhost:8080
```
